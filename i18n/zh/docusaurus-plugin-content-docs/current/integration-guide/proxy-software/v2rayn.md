# v2rayN 链式代理使用教程

***如果当前已有可用的境外网络环境，请按「v2rayN 配置」章节操作；如果当前无可用的境外网络环境，请按「链式代理」章节配置。***


006ip 是面向企业、开发者及跨境业务团队的住宅代理基础设施服务商，提供**动态住宅 IP、静态住宅 IP** 等产品。平台支持国家 / 地区及城市级定位，并可在后台配置 IP 白名单、认证方式和定位模式，适用于合规的数据采集、区域化页面测试、价格监控、广告验证及跨境业务环境维护等场景。

其中，**静态住宅 IP**能够提供长期固定的出口地址，更适合对网络环境连续性和连接稳定性有要求的业务。本教程将以 006IP 静态住宅代理为例，依次介绍账号注册、试用流量领取、代理购买和连接凭证导出，并演示如何在 **v2rayN** 中完成代理配置与连通性验证。

## 基础流程

### 1、注册并登录 006ip

第一步，打开 [006ip 中文官网](https://006ip.com/zh)，点击页面右上角的「**注册**」。已有账号的用户可直接点击「**登录**」。

![006ip 中文官网注册入口](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-homepage.png)

第二步，在注册页面选择以下任一方式完成注册：

#### 方式一：邮箱注册

选择「**邮箱注册**」，依次填写账号 / 邮箱、邮箱验证码、密码和确认密码。点击「**发送验证码**」后前往邮箱查收验证码，填写完成后勾选同意《服务协议》和《隐私政策》，再点击「**立即注册**」。

![006ip 邮箱注册](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-register-email.png)

#### 方式二：手机号注册

选择「**手机号注册**」，确认国家或地区区号后填写手机号，点击「**发送验证码**」并填写短信验证码。勾选同意《服务协议》和《隐私政策》后，点击「**立即注册**」。

手机号注册成功后会自动登录，账号初始为默认密码状态。请尽快前往账号设置中设置自己的登录密码。

![006ip 手机号注册](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-register-phone.png)

> 官网首页还提供「**使用 Gmail 账号注册**」快捷入口；如使用 Gmail，可按页面授权提示完成注册。

### 2、领取试用流量

006ip 官网当前提供新人试用活动：联系客服可免费领取 **1GB 试用流量**。具体领取条件、可用产品和有效期以活动页面及客服回复为准。

> 可以先用试用流量验证目标地区、协议兼容性和业务连通性，再决定正式套餐。

### 3、购买静态住宅代理

登录 006ip 用户后台后，在左侧导航栏点击「**静态代理**」，再按需选择「**静态住宅原生 IP**」或「**静态住宅广播 IP**」，进入购买页面。

购买页面提供「**快速模式**」和「**自定义模式**」两种配置方式。两种模式都会根据所选资源和配置实时核算价格，但适用需求不同。

![006ip 静态代理快速模式](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-purchase-quick-mode.png)

![006ip 我的 IP 列表](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-my-ip-list.png)

在「我的 IP」页面点击右上角的「**导出所有账号**」，选择适合客户端的代理格式。v2rayN 配置可使用标准格式：

## v2rayN 配置

本教程针对 **v2rayN** 客户端编写。v2rayN 是一款基于 V2Ray 内核的 Windows 代理工具，支持 SOCKS5 / HTTP 等多种协议的代理接入。以下步骤以 **v2rayN 7.x** 版本为准（6.x 及以下版本操作路径类似）。

配置前请确保你已经完成了上一节的购买流程，并拿到了代理连接信息（代理服务器地址、端口号、用户名、密码）。

### 1、准备代理连接信息

确认你手上有以下四项信息：

- **代理服务器地址**
- **端口号**
- **用户名**
- **密码**

> txt 文件每行格式为 `服务器地址:端口:用户名:密码`，可直接按顺序提取使用。

### 2、添加 HTTP / SOCKS5 代理服务器

打开 **v2rayN** 客户端，按以下步骤操作：

**① 通过「配置项」菜单新建服务器**

1. 点击顶部菜单栏的「**配置项**」。
2. 在下拉菜单中找到并点击「**添加 [HTTP]**」（如果你的代理协议是 SOCKS5，则选择「**添加 [SOCKS]**」），两者后续填写字段一致，仅协议类型不同。

![v2rayN 配置项菜单 — 选择添加[HTTP]](https://cdn.006ip.com/docs/img/guide/static-proxy/v2rayn-step1.png)

**② 填写代理连接参数**

弹出窗口后，依次填写以下字段：

| 参数项             | 填写内容                      | 说明                           |
| ------------------ | ----------------------------- | ------------------------------ |
| **别名 (remarks)** | `proxy1` 或任意便于识别的名称 | 用于在节点列表中区分不同服务器 |
| **地址 (address)** | 你的代理服务器地址            | xxx.xxx.xxx.xxx                |
| **端口 (port)**    | 你的端口号                    | 7778                           |
| **用户名 (可选)**  | 你的用户名                    | 006IP 代理认证账号             |
| **密码 (可选)**    | 你的密码                      | 006IP 代理认证密码             |

其余字段（底层传输方式、传输协议等）保持默认即可，无需修改。

![v2rayN 填写代理参数 — 地址/端口/账密](https://cdn.006ip.com/docs/img/guide/static-proxy/v2rayn-step2.png)

**③ 保存服务器**

确认以上五个关键字段填写无误后，点击「**确定**」。新添加的服务器会立即出现在 v2rayN 主界面的**服务器列表**中。

### 3、设为活动节点并测试延迟

**① 右键节点设为活动服务器**

在服务器列表中找到刚才添加的节点（如 `proxy1`），**右键点击它**，在弹出的菜单中选择「**设为活动**」（或直接双击该节点）。激活后节点名称旁会显示红色「**活动**」标记，表示当前选中状态。

同时你也可以在同一右键菜单中直接选择「**测试延迟 TcPing（多选）**」，快速检测该节点的连通性。

![v2rayN 右键节点 — 设为活动 & 测试延迟](https://cdn.006ip.com/docs/img/guide/static-proxy/v2rayn-step3.png)

> 如果你有多个 006IP 代理账号需要管理，可以重复第二步逐一添加，之后根据需要在节点间切换即可。

**② 查看测试结果**

延迟测试完成后，服务器列表右侧的「**延迟 (ms)**」列会显示出具体的延迟数值（如 `353`）。只要能看到数值（通常在数百毫秒范围内），说明代理连接通畅。

![v2rayN 测试通过 — 延迟正常显示](https://cdn.006ip.com/docs/img/guide/static-proxy/v2rayn-step4.png)

### 4、开启 Tun 模式并验证出口 IP

**① 开启 Tun 模式**

在 v2rayN 主界面**底部区域**，找到「**启用 Tun**」开关并将其打开（开关变为绿色即为已开启）。Tun 模式会接管系统所有网络流量，确保全部请求都通过你选中的代理 IP 发出。

![v2rayN 底部开启 Tun 模式 — 流量日志实时显示](https://cdn.006ip.com/docs/img/guide/static-proxy/v2rayn-step5.png)

> 如果你只需要浏览器走代理而其他应用不走，也可以选择底部「**清除系统代理**」旁的下拉菜单切换为 PAC 或仅代理模式。但对于数据采集、账号运营等场景，建议使用 **Tun 模式**以确保所有流量统一出口。

**② 验证代理是否生效**

完成以上全部步骤后，用以下两种方式验证：

**方法一：浏览器访问 IP 检测网站**

打开浏览器访问 `https://ipinfo.io` 或其他 IP 检测网站，检查返回的 **IP 地址和归属地**是否为你所选购地区的代理 IP。

![IPinfo检测结果示例 — 显示代理IP归属地](https://cdn.006ip.com/docs/img/guide/static-proxy/ipinfo-result.png)

如果显示正确（IP 归属地与选购的国家/地区一致），说明 **v2rayN 配置成功**。

> 如果 IP 检测显示的是你本地 IP，请按以下顺序排查：
>
> 1. 确认当前活动服务器是正确的 006IP 节点（列表中有红色「活动」标记的那个）
> 2. 确认「启用 Tun」开关已打开（绿色）
> 3. 确认填写的地址、端口、用户名、密码与后台信息完全一致（注意不要有多余空格）
> 4. 右键节点重新执行一次「测试延迟 TcPing」确认网络通畅

## 链式代理

如果你在国内网络环境下无法直接连接目标国家的后置代理，可以在 v2rayN 中配置**链式代理**：先连接一个当前网络可以正常使用的境外前置代理，再由前置代理连接后置代理。

链路顺序如下：

> **本机 → 前置代理（境外节点）→ 后置代理（目标国家）→ 目标网站**

例如，前置代理选择香港节点，后置代理选择美国节点。配置成功后，网站看到的最终出口应为**美国后置代理 IP**，而不是香港前置代理的 IP。

### 1、准备两组代理信息

开始前，请准备好以下信息：

| 节点角色 | 用途 | 示例别名 |
| --- | --- | --- |
| **前置代理** | 负责先将本地流量转发到境外，要求在当前网络下可以直接连接 | `proxy1-HK` |
| **后置代理** | 连接目标国家并作为最终业务出口 | `proxy2-US` |

两个节点都需要准备**地址、端口、用户名和密码**。建议使用容易区分的别名，并确保每个配置别名都是唯一的。

> 本节以 HTTP 代理为例。如果你的节点使用 SOCKS5 协议，请在添加节点时选择「**添加 [SOCKS]**」，其余流程相同。

### 2、创建前置代理分组

打开 v2rayN，点击顶部菜单栏的「**订阅分组**」，在弹出的「订阅分组设置」窗口中点击「**添加**」。

在「别名」中填写 `pre`（也可以使用其他容易识别的名称），其余选项保持默认，然后点击「**确定**」。这里不需要填写订阅 URL。

![v2rayN 创建前置代理分组](https://cdn.006ip.com/docs/img/v2rayn-chain-step1.png)

### 3、在 `pre` 分组中添加前置代理

返回 v2rayN 主界面后，按以下步骤添加前置代理：

1. 点击并选中刚创建的 `pre` 分组。
2. 点击顶部「**配置项**」→「**添加 [HTTP]**」。
3. 填写前置代理的别名、地址、端口、用户名和密码，例如将别名设置为 `proxy1-HK`。
4. 传输协议等其他参数保持默认，点击「**确定**」保存。

![v2rayN 在 pre 分组中添加前置代理](https://cdn.006ip.com/docs/img/v2rayn-chain-step2.png)

保存后，在 `pre` 分组中找到该节点，右键选择「**测试延迟 TcPing（多选）**」。能够显示延迟数值后，再将其设为活动节点，确认前置代理本身可以正常连接。

> 前置代理是整条链路的第一跳。如果该节点超时或无法连接，后置代理也无法使用。

### 4、创建后置代理分组并绑定前置代理

再次点击「**订阅分组**」→「**添加**」，创建用于存放后置代理的新分组。

1. 在「**别名**」中填写 `land`（名称可自定义）。
2. 找到「**前置代理配置别名**」，点击右侧的「**选择配置**」。
3. 在弹出的节点列表中选择刚才添加的前置代理，例如 `proxy1-HK`。
4. 确认选择无误后保存分组。

![v2rayN 创建后置代理分组并选择前置代理](https://cdn.006ip.com/docs/img/v2rayn-chain-step3.png)

> 请务必选择「**前置代理配置别名**」，不要误选下方的「落地代理配置别名」。本教程中，`proxy1-HK` 是前置代理，`proxy2-US` 是后置代理并负责最终出口。

### 5、在 `land` 分组中添加后置代理

回到主界面，点击并选中 `land` 分组，然后点击「**配置项**」→「**添加 [HTTP]**」。

填写后置代理的连接信息：

| 参数项 | 填写内容 |
| --- | --- |
| **别名 (remarks)** | 例如 `proxy2-US` |
| **地址 (address)** | 后置代理地址 |
| **端口 (port)** | 后置代理端口 |
| **用户名 (可选)** | 后置代理用户名 |
| **密码 (可选)** | 后置代理密码 |

其余参数保持默认，点击「**确定**」保存。由于 `land` 分组已经绑定了前置代理，该分组内的后置代理会通过 `proxy1-HK` 建立连接。

![v2rayN 在 land 分组中添加后置代理](https://cdn.006ip.com/docs/img/v2rayn-chain-step4.png)

### 6、启用后置代理并开启 Tun 模式

在 `land` 分组中找到刚添加的后置代理（如 `proxy2-US`），将其设为**活动节点**。确认节点旁出现红色「活动」标记后，在窗口底部打开「**启用 Tun**」开关。

此时，系统流量会按照以下顺序转发：

> **本机 → `proxy1-HK` → `proxy2-US` → 目标网站**

![v2rayN 启用后置代理并开启 Tun](https://cdn.006ip.com/docs/img/v2rayn-chain-step5.png)

> 最终需要设为活动的是 `land` 分组中的**后置代理**，不是 `pre` 分组中的前置代理。前置代理会由 v2rayN 按照分组设置自动调用。

### 7、检查最终出口 IP

打开浏览器访问 `https://ipinfo.io`，核对页面显示的 IP 地址和归属地。

![IPinfo检测结果示例 — 显示代理IP归属地](https://cdn.006ip.com/docs/img/guide/static-proxy/ipinfo-result.png)

验证结果应同时满足以下条件：

- 显示的 IP 与**后置代理 IP**一致。
- 国家或地区与购买的目标地区一致。
- 显示的不是本地公网 IP，也不是前置代理的出口 IP。

如果以上三项均正确，说明链式代理配置成功 ✅。

### 8、常见问题排查

**后置代理无法连接或一直超时**

1. 切换到 `pre` 分组，单独测试前置代理是否能显示延迟。
2. 检查 `land` 分组中的「前置代理配置别名」是否确实选择了 `proxy1-HK`。
3. 核对后置代理的地址、端口、用户名和密码，注意不要复制多余空格。
4. 保存修改后，点击顶部「**重启服务**」再重新测试。

**IP 检测显示的是前置代理所在地区**

说明当前活动节点可能仍是前置代理。请切换到 `land` 分组，将后置代理设为活动节点，然后重新打开 Tun 模式并刷新检测页面。

**IP 检测仍显示本地公网 IP**

确认底部「启用 Tun」开关为绿色，并尝试以管理员身份运行 v2rayN。如果浏览器或其他代理软件启用了独立代理设置，也应检查是否存在冲突。

**链式代理可以连接，但速度较慢**
