# NekoBox 链式代理使用教程（Windows 版）

***如果当前已有可用的境外网络环境，请按「NekoBox 配置」章节操作；如果当前无可用的境外网络环境，请按「链式代理」章节配置。***

006ip 是面向企业、开发者及跨境业务团队的住宅代理基础设施服务商，提供**动态住宅 IP、静态住宅 IP** 等产品。平台支持国家 / 地区及城市级定位，并可在后台配置 IP 白名单、认证方式和定位模式，适用于合规的数据采集、区域化页面测试、价格监控、广告验证及跨境业务环境维护等场景。

其中，**静态住宅 IP**能够提供长期固定的出口地址，更适合对网络环境连续性和连接稳定性有要求的业务。本教程将以 006IP 静态住宅代理为例，依次介绍账号注册、试用流量领取、代理购买和连接凭证导出，并演示如何在 **NekoBox（Windows）** 中完成代理配置与连通性验证。

## 基础流程

### 1、注册并登录 006ip

第一步，打开 [006ip 中文官网](https://006ip.com/zh)，点击页面右上角的「**注册**」。已有账号的用户可直接点击「**登录**」。

![006ip 中文官网注册入口](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-homepage.png)

第二步，在注册页面选择以下任一方式完成注册：

#### 方式一：邮箱注册

选择「**邮箱注册**」，依次填写账号 / 邮箱、邮箱验证码、密码和确认密码。点击「**发送验证码**」后前往邮箱查收验证码，填写完成后勾选同意《服务协议》和《隐私政策》，再点击「**立即注册**」。

![006ip 邮箱注册](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-register-email.png)

#### 方式二：手机号注册

选择「**手机号注册**」，确认国家或地区区号后填写手机号，点击「**发送验证码**」并填写短信验证码。勾选同意《服务协议》和《隐私政策》后，点击「**立即注册**」。

手机号注册成功后会自动登录，账号初始为默认密码状态。请尽快前往账号设置中设置自己的登录密码。

![006ip 手机号注册](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-register-phone.png)

> 官网首页还提供「**使用 Gmail 账号注册**」快捷入口；如使用 Gmail，可按页面授权提示完成注册。

### 2、领取试用流量

006ip 官网当前提供新人试用活动：联系客服可免费领取 **1GB 试用流量**。具体领取条件、可用产品和有效期以活动页面及客服回复为准。

> 可以先用试用流量验证目标地区、协议兼容性和业务连通性，再决定正式套餐。

### 3、购买静态住宅代理

登录 006ip 用户后台后，在左侧导航栏点击「**静态代理**」，再按需选择「**静态住宅原生 IP**」或「**静态住宅广播 IP**」，进入购买页面。

#### 第一步：选择购买模式并设置代理属性

购买页面提供「**快速模式**」和「**自定义模式**」两种配置方式。两种模式都会根据所选资源和配置实时核算价格，但适用需求不同。

##### （1）快速模式

快速模式适合希望直接使用平台默认网络配置、快速完成下单的用户。在此模式下，主要设置以下项目：

| 参数                  | 说明                                                                                                                   |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **独享级别**          | 可选择独享或共享。独享 IP 更适合对环境纯净度、稳定性和 IP 关联度要求较高的场景；共享 IP 更适合成本优先的常规访问场景。 |
| **国家 / 地区与城市** | 可按国家 / 地区和指定城市定位，也可选择随机范围进行国家级节点分布。                                                    |
| **订阅时长**          | 官方指南列出 30–365 天等周期；中长期套餐可能自动匹配阶梯折扣，最终以购买页面为准。                                     |
| **固定配置**          | 并发连接数（QPS）、端口带宽和 UDP 协议使用页面显示的默认配置。                                                         |

![006ip 静态代理快速模式](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-purchase-quick-mode.png)

##### （2）自定义模式

如需指定 IP 段，或需要调整连接数（QPS）、端口带宽和 UDP 协议，可开启「**自定义模式**」。该模式还支持选择业务用途、按城市和网段库存分配采购数量，并配置订阅时长。不同配置会影响最终计价，提交前应核对页面右侧的订单详情。

![006ip 静态代理自定义模式](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-purchase-custom-mode.png)

#### 第二步：确认订单并完成支付

进入订单确认页面后，系统会为所选 IP 资源锁定库存 **15 分钟**。如果超时未支付，资源会自动释放，需要重新下单。

006ip 官方指南列出的支付方式包括：

- **账户余额支付**；
- **在线支付**；
- **余额 + 在线支付**的组合支付。

当账户余额不足时，可先扣减余额，再通过页面提供的在线渠道补齐差额。使用账户余额抵扣时，需要输入在 006ip 平台设置的支付密码。在线渠道及可用币种以结算页面实际显示为准。

![006ip 订单确认与支付](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-order-payment.png)

### 4、查看并导出代理连接信息

支付成功后，进入左侧「**我的 IP**」菜单，即可查看已购买的静态 IP。列表会显示带宽、QPS、UDP 状态、有效期和资源状态，并支持续费、停用、启用及查看详情等操作。

![006ip 我的 IP 列表](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-my-ip-list.png)

配置 NekoBox 前，需要导出以下四项连接信息：

- **代理 IP 地址**
- **端口号**
- **用户名**
- **密码**

在「我的 IP」页面点击右上角的「**导出所有账号**」，选择适合客户端的代理格式。NekoBox 配置可使用标准格式：

```text
IP:PORT:USERNAME:PASSWORD
```

导出文件包含明文连接凭证。请妥善保存导出文件，不要通过公开聊天、截图或不受信任的渠道发送账密。

![006ip 导出账号凭证](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-export-credentials.png)

## NekoBox 配置

本教程针对 **NekoBox** 客户端编写。NekoBox 是一款代理工具，界面简洁直观，支持 SOCKS5 / HTTP 等多种协议，非常适合住宅代理的快速接入。以下步骤均以 **Windows 平台** 为准。

配置前请确保你已经完成了上一节的购买流程，并拿到了代理连接信息（代理服务器地址、端口号、用户名、密码）。同时请确认已安装 [NekoRay](https://github.com/MatsuriDayo/nekoray) 最新版本。

### 第一步：准备代理连接信息

确认你手上有以下四项信息：

- **代理服务器地址**
- **端口号**
- **用户名**
- **密码**

### 第二步：添加代理 IP

打开 **NekoBox** 客户端，按以下步骤操作：

#### ① 右键选择「手动输入配置」

启动 NekoBox 后，在主界面的**服务器列表空白区域右键单击**，在弹出的菜单中选择 **「手动输入配置」**。

![NekoBox右键手动输入](https://cdn.006ip.com/docs/img/guide/static-proxy/nekoray-step1.png)

#### ② 填写节点配置信息

在弹出的「**编辑**」窗口中，按如下方式填写：

| 字段     | 填写内容                       |
| -------- | ------------------------------ |
| **类型** | 选择 `Socks`（即 SOCKS5 协议） |
| **名称** | `proxy1` 或任意方便识别的名称  |
| **地址** | 你的代理服务器地址             |
| **端口** | 你的端口号（如 `7778`）        |

然后在下方的 **Socks** 区域填写认证信息：

| 字段       | 填写内容                           |
| ---------- | ---------------------------------- |
| **版本**   | `5`（表示 SOCKS5）                 |
| **用户名** | 你的代理用户名（如 `B_57164U...`） |
| **密码**   | 你的代理密码                       |

> 如果你在 006IP 后台获取的是 HTTP 协议代理，类型应改为对应 HTTP 选项；SOCKS5 对应选 `Socks`，版本设为 `5`。两者必须与后台一致，否则无法连通。

填写完毕后，点击窗口底部的 **「确定」** 保存节点。

![NekoBox编辑窗口](https://cdn.006ip.com/docs/img/guide/static-proxy/nekoray-step2.png)

### 第三步：确认节点已添加到列表

保存成功后，回到主界面，你可以在**服务器列表**中看到刚添加的节点信息：类型为 `Socks`，地址和名称均显示正确。

![NekoBox服务器列表](https://cdn.006ip.com/docs/img/guide/static-proxy/nekoray-step3.png)

> 如果你有多条代理（比如批量导出了多个账号），可以重复第二步的操作逐一添加，后续可在节点间自由切换。

### 第四步：启动节点并开启系统代理

确认以下两项均已就绪：

1. **开启 Tun 模式和系统代理**：在主界面顶部工具栏中，先勾选 **「Tun 模式」** 和 **「系统代理」** 两个选项（标题栏会出现 `[Tun+系统代理]` 标识）
2. **选中并启动节点**：在服务器列表中**勾选** 006IP 节点（左侧出现 ✓ 标记），然后**右键该节点 → 选择「启动」**

**启动成功后：**

- 标题栏显示 `[Admin] [Tun+系统代理] NekoBox ... [Socks] proxy1@默认`
- 节点右侧会显示**测试结果和流量数据**（如 `41.54 KiB ↑ | 162.74 KiB ↓`）
- 底部日志区域显示连接活动记录

![NekoBox启动节点](https://cdn.006ip.com/docs/img/guide/static-proxy/nekoray-step4.png)

打开浏览器访问 `https://ipinfo.io` 或其他 IP 检测网站，检查返回的 IP 地址是否为你所选购地区的代理 IP。如果显示正确，说明配置成功。

![IPinfo检测结果示例 — 显示代理IP归属地](https://cdn.006ip.com/docs/img/guide/static-proxy/ipinfo-result.png)

> 如果 IP 检测显示的是你本地 IP，请依次排查：
>
> 1. 「Tun 模式」和「系统代理」是否都已勾选
> 2. 服务器列表中的节点是否已勾选并启动
> 3. 节点编辑中的地址、端口、用户名、密码是否与 006IP 提供的信息完全一致
> 4. 协议类型（Socks / HTTP）是否与你购买时选择的协议一致

### 第五步：路由规则分流（可选）

如果你希望只有特定流量走 006IP 代理，而其他流量继续走原有节点或直连，可以使用 NekoBox 的**路由规则**功能实现分流。点击顶部菜单栏的 **「设置」**，在 **「路由规则」** 标签页中添加自定义规则，例如：

| 规则示例                                      | 含义                       |
| --------------------------------------------- | -------------------------- |
| 目标域名 `target-website.com` → 走 006IP 节点 | 只有访问该域名的请求走代理 |
| 目标 IP 段 `10.0.0.0/8` → 直连                | 局域网地址不经过代理       |
| 默认 → 直连 / 其他节点                        | 其余流量按需路由           |

这样只有匹配规则的流量才会通过 006IP 代理发出，其余流量保持原有路径不变。

## 链式代理

如果你在国内网络环境下无法直接连接目标国家或地区的代理服务器，可以在 NekoBox 中配置**链式代理**：先通过一个当前网络可以正常连接的境外前置代理建立通道，再连接目标国家或地区的后置代理。

链路顺序如下：

> **本机 → 前置代理（境外节点）→ 后置代理（目标国家/地区）→ 目标网站**

例如，使用香港代理作为前置代理、美国静态住宅代理作为后置代理。配置成功后，目标网站看到的最终出口应为**美国后置代理 IP**，而不是本地公网 IP 或香港前置代理 IP。

### 1、准备两组代理信息

开始前，请准备好以下两个节点的地址、端口、用户名和密码：

| 节点角色 | 用途 | 示例名称 |
| --- | --- | --- |
| **前置代理** | 负责先将本地流量转发到境外，必须能在当前网络环境下正常连接 | `proxy1-hk` |
| **后置代理** | 连接目标国家或地区，并作为最终业务出口 | `proxy2-us` |

建议选择距离本地较近、延迟较低且稳定的节点作为前置代理；后置代理则根据实际业务所需的国家或地区选择。

> 本节以两个 SOCKS5 节点为例。如果你的节点使用 HTTP 协议，请选择对应的 HTTP 类型，并确保协议与代理服务提供的信息一致。

### 2、添加境外前置代理

在 NekoBox 主界面的服务器列表空白处右键，选择「**手动输入配置**」，然后填写前置代理信息：

| 字段 | 填写内容 |
| --- | --- |
| **类型** | 选择 `Socks` |
| **名称** | 例如 `proxy1-hk` |
| **地址** | 前置代理服务器地址 |
| **端口** | 前置代理端口 |
| **版本** | 选择 `5` |
| **用户名 / 密码** | 前置代理的认证信息 |

填写完成后，点击「**确定**」保存。

![在 NekoBox 中添加境外前置代理](https://cdn.006ip.com/docs/img/nekobox-chain-step1.png)

> 前置代理是整条链路的第一跳。如果该节点无法连接或延迟过高，后置代理也会连接失败。建议保存后先单独测试该节点，确认能够正常使用。

### 3、添加目标国家或地区的后置代理

再次在服务器列表空白处右键，选择「**手动输入配置**」，填写后置代理信息：

| 字段 | 填写内容 |
| --- | --- |
| **类型** | 选择与后置代理一致的协议，本例为 `Socks` |
| **名称** | 例如 `proxy2-us` |
| **地址** | 后置代理服务器地址 |
| **端口** | 后置代理端口 |
| **版本** | SOCKS5 节点选择 `5` |
| **用户名 / 密码** | 后置代理的认证信息 |

填写完成后，点击「**确定**」保存。

![在 NekoBox 中添加目标国家或地区的后置代理](https://cdn.006ip.com/docs/img/nekobox-chain-step2.png)

保存后，服务器列表中应同时显示 `proxy1-hk` 和 `proxy2-us`。建议分别测试两个节点的连接信息，确认地址、端口、协议和账密没有填写错误。

### 4、创建链式代理并设置节点顺序

在服务器列表空白处右键，选择「**手动输入配置**」，按以下步骤创建代理链：

1. 将「**类型**」设置为「**链式代理**」。
2. 将名称填写为 `chain-proxy`，或其他便于识别的名称。
3. 点击「**选择配置**」，将 `proxy1-hk` 和 `proxy2-us` 加入链式代理列表。
4. 检查节点顺序：`proxy1-hk` 位于上方，`proxy2-us` 位于下方。
5. 点击「**确定**」保存链式代理。

![在 NekoBox 中创建链式代理并排列节点顺序](https://cdn.006ip.com/docs/img/nekobox-chain-step3.png)

> ⚠️ NekoBox 的链式代理流量顺序为**从上到下**，并将最后一个配置作为流量出口。因此本例必须保持 `proxy1-hk → proxy2-us` 的顺序。顺序颠倒会导致出口 IP 错误，甚至无法连接。

### 5、启动链式代理

回到 NekoBox 主界面后，按以下步骤启用代理链：

1. 在服务器列表中选中 `chain-proxy`。
2. 右键该条目并选择「**启动**」，确认左侧出现 ✓ 标记。
3. 勾选顶部的「**Tun 模式**」和「**系统代理**」。
4. 观察日志区域是否出现连接记录，并确认链式代理条目开始显示流量数据。

![在 NekoBox 中启动链式代理并开启 Tun 模式和系统代理](https://cdn.006ip.com/docs/img/nekobox-chain-step4.png)

> 需要启动的是 `chain-proxy` 链式代理条目，不是单独启动 `proxy1-hk` 或 `proxy2-us`。NekoBox 会按照链式代理中设置的顺序自动调用两个节点。

### 6、验证最终出口 IP

打开浏览器访问 `https://ipinfo.io` 或其他可信的 IP 检测网站，核对以下信息：

- 显示的 IP 是否与后置代理 IP 一致；
- 国家或地区是否与购买的目标线路一致；
- 显示的是否既不是本地公网 IP，也不是前置代理的出口 IP。

![IPinfo检测结果示例 — 显示代理IP归属地](https://cdn.006ip.com/docs/img/guide/static-proxy/ipinfo-result.png)

如果检测结果显示的是 `proxy2-us` 对应的目标 IP，说明链式代理已经配置成功。由于流量比单节点连接多经过一跳，延迟略有增加属于正常现象。

### 7、常见问题排查

| 现象 | 建议检查项 |
| --- | --- |
| 链式代理无法启动 | 分别核对两个节点的地址、端口、协议、用户名和密码，并先单独测试前置代理 |
| 后置代理一直超时 | 确认前置代理在当前网络下可以正常连接，并尝试更换延迟更低、更稳定的境外前置节点 |
| 检测结果是前置代理 IP | 检查链式代理列表是否缺少后置代理，或节点顺序是否写反；正确顺序应为 `proxy1-hk → proxy2-us` |
| 检测结果仍是本地公网 IP | 确认启动的是 `chain-proxy`，并检查「Tun 模式」和「系统代理」是否均已勾选 |
| 连接成功但速度较慢 | 链式代理会增加一跳，建议缩短前置节点距离、选择低延迟线路，并避免叠加不必要的代理层级 |
