# MaskFog 指纹浏览器配置 006IP 代理教程

***在使用 006IP 代理服务之前，请确保您的网络环境可以正常访问境外资源。如遇连接问题，请检查本地网络或联系客服获取协助。***


006ip 是面向企业、开发者及跨境业务团队的住宅代理基础设施服务商，提供**动态住宅 IP、静态住宅 IP** 等产品。平台支持国家 / 地区及城市级定位，并可在后台配置 IP 白名单、认证方式和定位模式，适用于合规的数据采集、区域化页面测试、价格监控、广告验证及跨境业务环境维护等场景。

其中，**静态住宅 IP**能够提供长期固定的出口地址，更适合对网络环境连续性和连接稳定性有要求的业务。本教程将以 006IP 静态住宅代理为例，依次介绍账号注册、试用流量领取、代理购买和连接凭证导出，并演示如何在 **MaskFog 指纹浏览器**中完成 006IP 代理配置与连通性验证。

## 基础流程

### 1、注册并登录 006ip

第一步，打开 [006ip 中文官网](https://006ip.com/zh)，点击页面右上角的「**注册**」。已有账号的用户可直接点击「**登录**」。

![006ip 中文官网注册入口](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-homepage.png)

第二步，在注册页面选择以下任一方式完成注册：

#### 方式一：邮箱注册

选择「**邮箱注册**」，依次填写账号 / 邮箱、邮箱验证码、密码和确认密码。点击「**发送验证码**」后前往邮箱查收验证码，填写完成后勾选同意《服务协议》和《隐私政策》，再点击「**立即注册**」。

![006ip 邮箱注册](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-register-email.png)

#### 方式二：手机号注册

选择「**手机号注册**」，确认国家或地区区号后填写手机号，点击「**发送验证码**」并填写短信验证码。勾选同意《服务协议》和《隐私政策》后，点击「**立即注册**」。

手机号注册成功后会自动登录，账号初始为默认密码状态。请尽快前往账号设置中设置自己的登录密码。

![006ip 手机号注册](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-register-phone.png)

> 官网首页还提供「**使用 Gmail 账号注册**」快捷入口；如使用 Gmail，可按页面授权提示完成注册。

### 2、领取试用流量

006ip 官网当前提供新人试用活动：联系客服可免费领取 **1GB 试用流量**。具体领取条件、可用产品和有效期以活动页面及客服回复为准。

> 可以先用试用流量验证目标地区、协议兼容性和业务连通性，再决定正式套餐。

### 3、购买静态住宅代理

登录 006ip 用户后台后，在左侧导航栏点击「**静态代理**」，再按需选择「**静态住宅原生 IP**」或「**静态住宅广播 IP**」，进入购买页面。

#### 第一步：选择购买模式并设置代理属性

购买页面提供「**快速模式**」和「**自定义模式**」两种配置方式。两种模式都会根据所选资源和配置实时核算价格，但适用需求不同。

##### （1）快速模式

快速模式适合希望直接使用平台默认网络配置、快速完成下单的用户。在此模式下，主要设置以下项目：

| 参数                  | 说明                                                                                                                   |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **独享级别**          | 可选择独享或共享。独享 IP 更适合对环境纯净度、稳定性和 IP 关联度要求较高的场景；共享 IP 更适合成本优先的常规访问场景。 |
| **国家 / 地区与城市** | 可按国家 / 地区和指定城市定位，也可选择随机范围进行国家级节点分布。                                                    |
| **订阅时长**          | 官方指南列出 30–365 天等周期；中长期套餐可能自动匹配阶梯折扣，最终以购买页面为准。                                     |
| **固定配置**          | 并发连接数（QPS）、端口带宽和 UDP 协议使用页面显示的默认配置。                                                         |

![006ip 静态代理快速模式](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-purchase-quick-mode.png)

##### （2）自定义模式

如需指定 IP 段，或需要调整连接数（QPS）、端口带宽和 UDP 协议，可开启「**自定义模式**」。该模式还支持选择业务用途、按城市和网段库存分配采购数量，并配置订阅时长。不同配置会影响最终计价，提交前应核对页面右侧的订单详情。

![006ip 静态代理自定义模式](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-purchase-custom-mode.png)

#### 第二步：确认订单并完成支付

进入订单确认页面后，系统会为所选 IP 资源锁定库存 **15 分钟**。如果超时未支付，资源会自动释放，需要重新下单。

006ip 官方指南列出的支付方式包括：

- **账户余额支付**；
- **在线支付**；
- **余额 + 在线支付**的组合支付。

当账户余额不足时，可先扣减余额，再通过页面提供的在线渠道补齐差额。使用账户余额抵扣时，需要输入在 006ip 平台设置的支付密码。在线渠道及可用币种以结算页面实际显示为准。

![006ip 订单确认与支付](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-order-payment.png)

### 4、查看并导出代理连接信息

支付成功后，进入左侧「**我的 IP**」菜单，即可查看已购买的静态 IP。列表会显示带宽、QPS、UDP 状态、有效期和资源状态，并支持续费、停用、启用及查看详情等操作。

![006ip 我的 IP 列表](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-my-ip-list.png)

配置 MaskFog 前，需要准备以下四项连接信息：

- **代理 IP 地址**
- **端口号**
- **用户名**
- **密码**

在「我的 IP」页面点击右上角的「**导出所有账号**」，选择适合客户端的代理格式。可使用标准格式：

```text
HOST:PORT:USERNAME:PASSWORD
```

导出文件包含明文连接凭证。请妥善保存导出文件，不要通过公开聊天、截图或不受信任的渠道发送账密。

![006ip 导出账号凭证](https://cdn.006ip.com/docs/img/guide/static-proxy/006ip-export-credentials.png)

购买与账密导出流程以 [006ip 静态代理使用指南](https://docs.yangtuip.com/zh/static-proxy-user-guide/) 和后台页面的最新提示为准。

## MaskFog 指纹浏览器配置

完成上述流程并获取 006IP 代理的服务器地址、端口、用户名和密码后，即可将代理添加到 MaskFog 浏览器环境中。

### 1、新建浏览器环境

打开 **MaskFog**，在左侧点击「**新建浏览器**」。

![MaskFog 新建浏览器](https://cdn.006ip.com/docs/img/static-proxy/config-tutorial/maskfog-1.png)

进入「**新建浏览器环境**」页面后，先填写环境名称，并根据需要设置浏览器、User Agent 等基础信息。

![MaskFog 新建浏览器环境](https://cdn.006ip.com/docs/img/static-proxy/config-tutorial/maskfog-2.png)

在「**设备配置**」中，将「**代理方式**」选择为「**自定义设备**」，然后点击「**选择设备**」。

### 2、配置 006IP 代理设备

在弹出的「**选择设备**」页面中，找到一个可配置的设备，点击「**配置设备**」。

![MaskFog 配置设备](https://cdn.006ip.com/docs/img/static-proxy/config-tutorial/maskfog-3.png)

进入「**编辑设备**」后，根据上一节从 006IP 后台获取的代理连接信息填写：

| MaskFog 配置项 | 填写说明 |
| --- | --- |
| **设备名称** | 自定义名称，方便后续识别，例如 `proxy1`。 |
| **代理类型** | 选择与 006IP 当前代理一致的协议，例如 `HTTP`、`HTTPS` 或 `SOCKS5`。 |
| **主机** | 填写 006IP 提供的代理服务器地址。 |
| **端口** | 填写对应的代理端口。 |
| **账号** | 填写 006IP 提供的代理用户名。 |
| **密码** | 填写对应的代理密码。 |
| **备注** | 可选，根据需要填写。 |

例如，若从 006IP 导出的账号格式为：

```text
HOST:PORT:USERNAME:PASSWORD
```

则对应填写关系如下：

```text
HOST      → MaskFog「主机」
PORT      → MaskFog「端口」
USERNAME  → MaskFog「账号」
PASSWORD  → MaskFog「密码」
```

![MaskFog 填写 006IP 代理信息](https://cdn.006ip.com/docs/img/static-proxy/config-tutorial/maskfog-4.png)

> **注意：** MaskFog 中选择的代理类型必须与 006IP 当前代理实际使用的协议一致。如果协议选择错误，即使主机、端口、账号和密码填写正确，也可能无法正常连接。

### 3、检测并绑定代理

填写完成后，点击右侧的「**检查网络**」。

![MaskFog 检查网络](https://cdn.006ip.com/docs/img/static-proxy/config-tutorial/maskfog-5.png)

如果页面显示「**连接测试成功！**」，并能正常识别代理出口 IP、国家/地区、州/省和城市等信息，说明当前 006IP 代理连接正常。

确认代理可用后，点击底部的「**确定**」保存设备配置。

返回「**选择设备**」页面后，可以看到刚刚配置的设备及代理名称。点击该设备右侧的「**绑定**」，将其绑定到当前浏览器环境。

![MaskFog 绑定代理设备](https://cdn.006ip.com/docs/img/static-proxy/config-tutorial/maskfog-6.png)

绑定完成后，返回新建浏览器环境页面，在「**选择设备**」一栏可以看到已绑定的设备名称。

![MaskFog 已绑定设备](https://cdn.006ip.com/docs/img/static-proxy/config-tutorial/maskfog-7.png)

### 4、创建并启动浏览器环境

确认设备和代理已经绑定后，点击页面左下角的「**确定**」创建浏览器环境。

创建完成后，会返回「**账号管理**」页面。找到刚刚创建的环境，点击右侧的「**打开**」。

浏览器启动后，该环境会通过已配置的 006IP 代理连接网络。

![MaskFog 启动浏览器环境](https://cdn.006ip.com/docs/img/static-proxy/config-tutorial/maskfog-8.png)

如需进一步确认代理是否生效，也可以在当前 MaskFog 浏览器环境中访问 `https://ipinfo.io` 或其他 IP 检测网站，检查当前显示的出口 IP 是否与 006IP 代理一致。

### 5、常见问题排查

| 现象 | 建议检查项 |
| --- | --- |
| 无法连接代理 | 检查主机和端口是否填写正确，并确认当前 006IP 代理仍然有效。 |
| 提示认证失败 | 重新核对 006IP 提供的账号和密码，避免复制时带入空格。 |
| 检查网络失败 | 检查本地网络是否能够正常连接代理服务器。 |
| 已填写账密但仍无法使用 | 确认 MaskFog 中选择的代理类型与 006IP 实际代理协议一致。 |
| 浏览器启动后显示本地 IP | 确认代理设备已保存，并已绑定到当前浏览器环境。 |
| 检测地区与预期不一致 | 核对当前填写的 006IP 代理是否为所购买的目标国家 / 地区或城市节点。 |

> 不同 MaskFog 版本的界面布局或按钮名称可能略有差异，请以当前客户端实际界面为准。请仅将代理用于合法合规的业务场景，并遵守目标网站的服务条款及当地法律法规。
