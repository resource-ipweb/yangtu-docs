# 006ip 无限住宅流量使用指南

## 一、如何购买无限住宅流量？

登录 006ip 的用户后台，左侧点击 **无限住宅流量 > 套餐购买**。在这个页面，根据实际使用需求选择套餐参数并完成支付。

### 步骤 1：选择套餐参数

在 **套餐购买** 页面依次设置以下参数：

- **专用服务器**：选择与你的业务服务器网络更近的代理主机入口，通常有助于降低连接延迟。
- **带宽**：选择套餐可用的带宽规格，例如 `100 Mbps`、`200 Mbps`、`300 Mbps`、`1000 Mbps`；如需更高带宽，可选择 **自定义** 并联系销售获取报价。
- **服务周期**：选择套餐使用时长，例如 `30 天`、`60 天`、`90 天`、`180 天` 或 `360 天`。

![无限量代理套餐购买页面](https://cdn.006ip.com/docs/img/unlimited-proxy/zh/unlimited-purchase-plan.png)

> 专用服务器这里选择的是代理主机（入口网关）所在地区，不是住宅出口 IP 的国家。开通后系统会分配主机和端口；主机是连接地址，端口是该地址的网络通道，两者需与账密一起使用。优先选择距离发起请求的业务服务器网络更近的地区，通常有助于降低连接延迟。住宅出口国家请在使用代理时单独选择。

无限住宅流量采用 **带宽与服务周期** 作为主要套餐规格，在套餐有效期内流量不限量。实际可用带宽以所购买的套餐规格为准。

参数选择完成后，可在页面右侧的 **订单详情** 中确认：

- 产品类型
- 带宽
- 国家/地区
- 服务周期
- 订单总金额

确认订单信息无误，并阅读同意 **《服务协议》** 和 **《隐私政策》** 后，点击 **立即购买** 创建订单。

### 步骤 2：选择支付方式

订单创建后会进入支付页面。006IP 支持 **账户余额支付** 和 **在线支付** 两种方式。

#### 方式一：账户余额支付

如果账户余额充足，可勾选 **使用账户可用余额**。

勾选后，系统会优先使用当前账户余额支付订单。确认页面显示的 **应付总额** 和 **余额支付** 金额无误后，点击 **立即支付**。

如果账户余额不足，可先为账户充值，或取消余额支付并选择在线支付。

![无限量代理余额支付页面](https://cdn.006ip.com/docs/img/unlimited-proxy/zh/balance-payment.png)

提示：

- 待支付订单的资源库存会临时锁定，页面显示的锁定时间为 **15 分钟**，建议在有效时间内完成支付。
- 如需套餐到期后自动续费，可在支付页面勾选 **启用自动续费（余额扣费）**。开启后请确保账户余额充足，以免续费时因余额不足导致扣款失败。
- 购买前请重点核对国家/地区、带宽和服务周期。不同套餐规格对应的价格可能不同。

#### 方式二：在线支付

如不使用账户余额，可取消勾选 **使用账户可用余额**，然后在 **在线支付** 区域选择可用的支付渠道。

当前页面支持的支付方式包括：

- 支付宝
- 银联
- USDT（`TRC20`）
- 支付宝（香港）

选择支付渠道后，点击 **立即支付**，按照页面提示完成付款。

![无限量代理在线支付页面](https://cdn.006ip.com/docs/img/unlimited-proxy/zh/online-payment.png)

支付成功后，系统会开始为当前订单配置无限住宅流量线路。

从订单确认到线路生成通常需要约 **3 到 5 分钟**。线路配置完成后，即可在无限住宅流量后台查看和使用已购买的代理资源。

## 二、查看已购买的无限住宅流量

无限住宅流量套餐开通完成后，可在 006IP 用户后台查看对应的服务实例、代理账密及连接信息。

### 步骤 1：进入获取代理

点击左侧的 **获取代理**，进入页面后，系统会显示当前选中的无限住宅流量服务，包括：

- **服务主机**
- **服务实例**
- **服务状态**
- **带宽**
- **剩余时间**

当服务状态显示为 **使用中** 时，表示当前实例已正常开通，可以继续查看并使用对应的代理连接信息。

### 步骤 2：查看已购买的服务实例

点击页面右上角的 **我的服务**。

![无限量代理我的服务入口](https://cdn.006ip.com/docs/img/unlimited-proxy/zh/my-services-entry.png)

在 **我的服务** 列表中，可以查看当前账户下的所有无限住宅流量实例。每个实例会显示：

- 服务实例名称
- 服务实例编号
- 当前状态
- 带宽
- 代理主机
- 服务周期
- 剩余时间

可通过顶部搜索框按 **名称或实例编号** 查找服务，也可以按照服务状态进行筛选。

找到需要使用的实例后，点击对应服务，即可切换到该实例的代理详情页面。

![无限量代理服务实例列表](https://cdn.006ip.com/docs/img/unlimited-proxy/zh/service-instance-list.png)

服务列表中的带宽、服务周期和剩余时间均对应具体实例。账户下存在多个套餐时，使用代理前请确认当前选择的是正确的服务实例。

### 步骤 3：查看代理账密

选中需要使用的服务实例后，在 **账密连接** 页面查看该实例对应的代理连接信息。

**账密信息** 区域主要包括：

- **代理主机**：连接代理服务器时使用的主机地址。
- **代理账户**：当前无限住宅流量服务生成的基础用户名。
- **代理密码**：连接代理服务器时使用的认证密码。
- **代理串**：系统根据当前配置生成的完整代理连接信息，可直接复制使用。

![无限量代理账密信息](https://cdn.006ip.com/docs/img/unlimited-proxy/zh/credentials-panel.png)

每项信息右侧均提供复制按钮，可直接复制到浏览器、代理客户端、指纹浏览器或程序代码中进行配置。

如需查看代理密码，可点击密码右侧的显示按钮；如需更换密码，可点击 **修改密码**。

> 请妥善保管代理账户和密码，不要将账密信息公开或共享给无关人员。

## 三、导出的代理各项内容代表什么？

006ip 严格依据 SOCKS5/HTTP 代理协议，Socks5/HTTP 代理（账号密码模式）格式如下：

```text
U_{账号}_{country_code}_{area_id}_{city_id}_{time}_{sid}:{密码}@{代理服务器}:{端口号}
```

### 示例说明

**示例代理信息：**

```text
U_63j7gpxb00_000___5_V97E147405:PdnVkSrJbZS8@139.162.18.5:7778
```

**各项内容解析：**

- **账号**：`63j7gpxb00`，无限住宅流量服务用户账号，固定不变。
- **国家代码**：`000`，例如 `AF` 表示阿富汗；`000` 表示全球随机。
- **地区/州代码**：例如 `1674` 表示 Kabul；如果留空，则会在所选国家内随机分配州或地区。
- **城市代码**：例如 `11220` 表示 Kabul；如果留空，则会在所选州或地区内随机分配城市。
- **IP 持续时间**：`5`，单位为分钟，可设置范围为 `5` 到 `90`。到期后会自动更换出口 IP，但不会中断当前连接。
- **SID**：`V97E147405`，会话标识，可由字母和数字组成，最长 `12` 位。修改 SID 可以生成独立的代理会话。
- **代理密码**：`PdnVkSrJbZS8`
- **代理服务器**：`139.162.18.5`
- **端口号**：`7778`，同时支持 SOCKS5 和 HTTP(S)，切换协议时无需修改端口。

![无限量代理串字段说明](https://cdn.006ip.com/docs/img/unlimited-proxy/zh/proxy-string-breakdown.png)

### 验证代理有效性

让我们验证一下上面导出的这条代理是否有效。可以通过以下 `curl` 命令进行验证：

```bash
curl -x http://U_63j7gpxb00_000___5_V97E147405:PdnVkSrJbZS8@139.162.18.5:7778 ipinfo.io -v
```

![无限量代理 curl 验证结果](https://cdn.006ip.com/docs/img/unlimited-proxy/zh/curl-verification.png)

执行成功后，将返回当前代理 IP 以及对应的地理位置信息。
