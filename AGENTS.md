# AGENTS.md — 006ip-docs

Documentation site for **006ip** (proxy product docs + Open Platform API reference). Static **Docusaurus 3** site with **i18n** (`en` default, `zh`). Not a Next.js app.

---

## Tech stack

| Layer | Choice | Notes |
|-------|--------|--------|
| Runtime | Node.js ≥ 20 | `engines` in `package.json` |
| Package manager | **pnpm** | Use `pnpm`, not npm/yarn |
| Site generator | **Docusaurus 3.10** (`@docusaurus/preset-classic`) | Docs at site root (`routeBasePath: '/'`) |
| Language | TypeScript 5.6 | `pnpm typecheck` → `tsc` |
| Content | Markdown / MDX | User guides + API docs under `docs/` |
| API doc codegen | `scripts/generate-api-docs.mjs` | Clones `006ip-Open-platform`, Redocly → MD |
| Diagrams | `@docusaurus/theme-mermaid` | Mermaid in markdown |
| Syntax highlight | `prism-react-renderer` | Themes in `docusaurus.config.ts` |
| CI / deploy | GitHub Actions | S3 + optional EC2 sync (`.github/workflows/deploy-s3.yml`) |

---

## Architecture

```
Browser (/:locale/...)
    │
    ├─► Layout: Sidebar + TopNav + Footer
    │
    ├─► Doc pages (@theme/DocItem/Content) + MDX
    │
    └─► Optional iframe embed on docs.yangtuip.com (EmbedLayout)

Build: pnpm build → generate-api-docs.mjs → docusaurus build → build/ + build/zh/
Deploy: GitHub Actions → S3 (EN + zh) + SSM sync on EC2
```

## Key commands

| Command | Purpose |
|---------|---------|
| `pnpm start` | Dev server (EN default) |
| `pnpm start:zh` | Dev with `-l zh` |
| `pnpm build` | Regenerate API docs + production build (EN + zh) |

| `pnpm gen:api-docs` | Run Open API → Markdown pipeline only |

| `pnpm clear` | Clear Docusaurus cache |

## Environment and deployment

**Build-time (local / CI)**

- **`OPEN_API_REPO_TOKEN`** (or **`GITHUB_TOKEN`** in Actions): clone private repo `006ip-Open-platform` in `generate-api-docs.mjs`.
- **`OPEN_API_REPO_REF`** (optional): branch/ref to checkout (default **`develop`**).

**Runtime**

- Static site; no app server. Hosting is S3 + optional EC2 sync per workflow.

**URLs**

- Production: `https://docs.yangtuip.com` (`url` in config).
- EN: `/`; zh: `/zh/` (`localeConfigs`).

## Conventions for agents

- **Default reply language:** 简体中文 (see parent `d:\work2\AGENTS.md` if present).
- **Doc changes:** English source in `docs/`; mirror Chinese under `i18n/zh/docusaurus-plugin-content-docs/current/`.
- **Sidebar order:** `sidebar_position` on pages; `position` in `_category_.json` for categories.
- **Images:** Doc screenshots use CDN `https://cdn.006ip.com/docs/img/...` (no spaces in filenames). Keep `favicon.ico` and `logo.svg` local under `static/img/`.
- **Minimal diffs:** Match existing markdown/frontmatter style; do not commit unless asked.
- **Before editing:** Read target files first; do not overwrite user edits.

## Gotchas

- **`pnpm build` always runs API doc generation**; without token, clone fails—use **`pnpm build:fast`** for docs-only builds.
- **`onBrokenLinks: 'throw'`** — broken internal links fail the build.
- **i18n parity:** New EN pages may need zh copies under `i18n/zh/.../current/`.
- **`trailingSlash: true`** — use trailing slashes in internal links.
- **Embed mode:** `src/utils/embedInsertMode.ts` adjusts layout when embedded in iframe on product domain.
- **User rules mentioning Next.js / Shadcn:** This repo is Docusaurus-only; ignore Next-specific paths unless added later.
